How to Run on Localhost

Install XAMPP

Make sure Apache and MySQL are available.

Move the Project Folder

Copy Capstone2.1 into:
C:\xampp\htdocs

Start the Server

Open XAMPP Control Panel

Start Apache

Start MySQL

Open the Project

Go to your browser

Type:
http://localhost/Capstone2.1

Database Setup (if needed)

Open: http://localhost/phpmyadmin

Create a database (example: capstone_db)

Import the .sql file from the project

Check Database Config

In your project, make sure the DB settings are:

Host: localhost

User: root

Password: (empty)

Database name: capstone_db

Done

Your project should now run on localhost.
